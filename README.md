# ISM4641 Course Data — Fall 2026

Public datasets for **ISM4641 Python for Business Analytics**, Fall 2026 (University of South Florida, Dr. Tim Smith).

These datasets are loaded directly by the lecture-notes, assignment, practice, and business-case notebooks in the course. Notebooks reference files via raw GitHub URLs:

```python
import pandas as pd
DATA_URL = "https://raw.githubusercontent.com/prof-tcsmith/4641Fall26-DATA/main/data"
df = pd.read_csv(f"{DATA_URL}/week05/transactions.csv")
```

**All data in this repository is synthetic.** Companies, people, transactions, and measurements are fictional, generated for teaching. Any resemblance to real businesses or persons is coincidental.

## Layout

Folders follow the **Fall 2026 week numbering** (14-week course: 12 content weeks, midterm in Week 8, final exam in Week 14 — no data folders for exam weeks):

```
data/
├── week01/   # Intro to Python — business-case data (Bay Breeze Smoothies)
├── week02/   # Control Flow & Data Structures — business-case data (SunCoast Fitness)
├── week03/   # Functions & Modules — business-case data (Gulf Getaways)
├── week04/   # NumPy — business-case data (TampaTech Manufacturing)
├── week05/   # Pandas Fundamentals — GreenLeaf Markets loyalty + supporting CSVs
├── week06/   # Data Wrangling & Cleaning — messy GreenLeaf extracts for cleanup
├── week07/   # Data Visualization — CloudMetrics + FreshBrew Coffee + Palmetto Power
├── week09/   # Statistics — BrewRight + SwiftStay Hotels + HarborView Hotels
├── week10/   # Simple Linear Regression — used cars, salaries + Citrus Logistics
├── week11/   # Multiple Regression — HomeValue Partners / properties + BayView Realty
├── week12/   # Logistic Regression — TrustFirst Credit Union + Gator Financial CU
```

Some weeks read files from an earlier week's folder (e.g., Week 6 wrangling reuses Week 5's GreenLeaf tables alongside its own messy extracts). Files are never moved or renamed once the semester starts — notebooks depend on stable URLs.
